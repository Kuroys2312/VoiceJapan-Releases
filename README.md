# KuroYs Voice Japan: bản phát hành công khai

Repo công khai của app **KuroYs Voice Japan**: tạo giọng đọc tiếng Nhật, clone giọng và xuất phụ đề SRT.
Mã nguồn app không nằm ở đây.

## Nội dung

| Thư mục / tag | Là gì |
|---|---|
| [`colab_japan/`](colab_japan/) | Notebook Google Colab để huấn luyện (clone) giọng trên GPU miễn phí, dành cho máy yếu. Xem [colab_japan/README.md](colab_japan/README.md) |
| tag `vj-colab-v1`, `vj-colab-v2`, … (mới nhất: `vj-colab-v4`) | Phiên bản notebook. Tag đã phát hành không bao giờ dời; notebook thay đổi thì ra tag mới |

Mở notebook bằng nút **"Mở trang Colab"** trong app, để luôn đúng phiên bản app cần.

Mã trong `colab_japan/` theo giấy phép GNU AGPL v3 (xem `colab_japan/LICENSE`).
